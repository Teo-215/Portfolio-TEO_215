Decoupling Core Logic: Building the FacilEase Workshop Matrix

Recent Build PHP CodeIgniter 4 React JS Relational Modeling

Wrapping up the final release candidate of the FacilEase workshop management system forced an insightful structural pivot. Standard asset logging systems often treat storage assets and functional spatial items identically. For this solution, I abstracted facility booking constraints completely into their own standalone query structures to avoid indexing bottlenecks during peak scheduling windows.

The application uses a modular PHP CodeIgniter 4 server backend serving optimized JSON payloads directly to an interactive React context layer. By processing user session filtration criteria states directly inside memory collections, client-side view changes remain immediate, and user credentials stay robustly contained behind state security checks.

Physical Computing Sync: Real-Time Signal Processing with ESP8266

Hardware Log ESP8266 Firmware Arduino Core Biometrics

This hardware integration track targets multi-dimensional athlete performance telemetry under high stress. The prototype physical module coordinates data metrics from dual axes: grabbing sudden impact velocity thresholds using high-accuracy G-force accelerometers, while concurrently capturing cardiovascular feedback metrics via an integrated optical pulse sensor array.

A major design roadblock emerged during physical prototyping—filtering high-frequency hardware signal hum and erratic spikes from the continuous data channel. Writing data collection constraints inside the native Arduino core environment allowed me to balance signal fluctuations smoothly before emitting data packets to an active OLED interface.

Java Spring Boot Architecture: Engineering a Low-Latency Forex Utility

Utility Deployment Java Spring Boot API Integration State Ledgers

To streamline a personal currency tracking workflow, I engineered a highly responsive, standalone MYR to SGD currency conversion tracking tool. While common web utilities provide generic current values, this application allows for granular, state-driven history logging with localized transaction records.

The backend microservices layout leverages Java Spring Boot to capture regional exchange rates securely. To provide depth beyond typical math calculations, the persistence tier maps conversion behaviors to an explicit ledger framework, tracking historical conversion rates alongside custom user tracking inputs across relational SQL schemas.
